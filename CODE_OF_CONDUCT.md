# Contributor Covenant Code of Conduct

## Our Pledge

Contributors and maintainers pledge to make participation in the **Spring-NWVMC** community respectful, welcoming, and free from harassment for everyone regardless of background or experience level.

## Expected Behavior

- Focus technical feedback on architecture, security, performance, and API clarity.
- Respect differing technical viewpoints and provide reproducible evidence in bug reports.
- Keep documentation, commit messages, and code reviews constructive.

## Unacceptable Behavior

- Harassment, personal attacks, or derogatory remarks in issues, pull requests, or community forums.
- Publishing private information (credentials, personal emails, tokens) without authorization.

## Enforcement

Instances of abusive or unacceptable behavior may be reported to the repository maintainers via GitHub Security Advisories or private maintainer contact. Maintainers will review and respond promptly.
